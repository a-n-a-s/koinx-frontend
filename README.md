# Tax Loss Harvesting Dashboard

A beautifully designed, highly responsive web application built to simulate and visualize Tax Loss Harvesting scenarios.

## 🚀 Features
- **Dynamic Tax Calculations**: Real-time computation of Pre and Post-Harvesting Capital Gains (Short Term & Long Term).
- **Interactive Holdings Table**: Master/individual selection checkboxes to simulate the impact of selling losing assets on your tax liability.
- **Premium UI/UX**: Fully responsive mobile-first design featuring modern skeleton loading states, CSS-only tooltips, and smooth accordions.
- **Dark Mode**: Native and seamless dark/light mode integration built completely with Tailwind CSS v4 custom variants.
- **API Simulation**: Mock async data fetching demonstrating professional loading and error handling states.
- **View All functionality**: Smart pagination logic restricting initial rendering to 4 rows for better UI/UX.

## 🛠️ Tech Stack
- **Framework:** React 19 + Vite
- **Styling:** Tailwind CSS v4
- **State Management:** React Hooks (`useState`, `useMemo`, `useEffect`)

## 💻 Local Development

1. Navigate to the project directory:
   ```bash
   cd frontned
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

## 🌐 Deployment
This project is perfectly optimized for free hosting platforms like **Vercel** or **Netlify**. 
- Build command: `npm run build`
- Output directory: `dist`
